# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v1.6    | :white_check_mark: |
| < v1.5  | :x:                |

## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

1.  **Do not create a public GitHub issue.**
2.  Email details to `security@aetheros.org` (Placeholder).
3.  We will respond within 48 hours.

## CVE Response Process

1.  **Triage**: Verify the vulnerability and assess severity (CVSS).
2.  **Patch**: Develop a fix in a private branch.
3.  **Review**: Internal code audit of the fix.
4.  **Release**: Publish a security advisory and patched release.
5.  **Disclosure**: Publicly disclose the CVE after a grace period.
